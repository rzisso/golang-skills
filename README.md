# Golang-skills
Golang Skills for Cline and other AI Agents

### Installation
```bash
# Clone the repository
git clone https://github.com/rzisso/golang-skills.git
cd golang-skills

# Grant execution rights and run the installer
chmod +x cline_install.sh
./cline_install.sh
```
